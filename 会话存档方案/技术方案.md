# 技术方案 — 会话存档路径

## 一、目标

同旧方案:每天扫 400-500 个督学外部群的当日聊天,按规则判定服务是否完成,推送内部管理群机器人。

## 二、跟旧方案的替换点

| 层 | 旧 (MCP) | 新 (存档) |
|---|---|---|
| 消息读取 | wecom-cli MCP 授权用户身份 | 官方「会话内容存档」SDK + RSA 解密 |
| 群识别 | chat_name 解析编号 | roomid ↔ 编号(通过 msgaudit/groupchat/get 拿群名反解) |
| 拉取模式 | 现读 | 增量拉 + 本地缓冲(seq 游标) |
| 数据保留窗口 | 官方 7 天 | 官方 5 天(**必须频繁拉,不能只等 22:00**) |
| 客户机要求 | Mac 本机 | Mac + Docker(SDK 只有 Linux 版) |
| 授权 | 7 天 renew | 一次开通长期 |
| 合规 | 灰色 | 官方合规 |
| 成本 | 免费 | ~900 元/员工/年,5 人起 |

## 四、数据流

### 每小时(fetch)

```
seq = read_seq()
loop:
    encrypted_batch = sdk.get_chat_data(seq, limit=1000)
    for enc in encrypted_batch:
        plain = sdk.decrypt(enc.random_key, enc.chat_msg)  # RSA + AES
        row = normalize(plain)   # 抽 msgid, roomid, from, ts, msgtype, content
        append archive_msgs.csv
        seq = max(seq, enc.seq)
    write_seq(seq)
```

### 每天 22:00(daily_check)

```
roster = load_roster(xlsx, today)  # 过滤在服务期
upsert students.csv                 # roomid 列保留 sync_rooms 填的值
for r in roster:
    msgs = read_archive_msgs_for_day(roomid=r.roomid, date=today)
    verdict = judge(msgs, r.subject, rules)   # hashtag 判定
append_checks(verdicts)
cleanup old checks + old archive_msgs
push_wecom_bot(markdown_summary)
```

### 每周一 09:00(sync_rooms)

```
for roomid in unique_roomids(archive_msgs.csv):
    name = msgaudit.groupchat.get(roomid).name   # 拿群名
    gid = parse_id_from_name(name)               # "e123 政治+英语" → e123
    mapping[gid] = roomid
update_students_csv(mapping)
write unmatched_rooms.csv for 主管人工处理
```

## 七、关键风险

| 风险 | 影响 | 应对 |
|---|---|---|
| SDK 拉取器挂 > 5 天 | 服务端消息永久丢失 | workbuddy 每小时心跳,seq.txt mtime 超时告警 |
| 部分客户点了"不同意存档" | 那部分群消息缺失 | 存档管理端**不勾**"限制服务",不同意的群标数据不全交人工 |
| 群名不符合命名规则 | roomid 匹配不上 | sync_rooms 兜底写 unmatched_rooms.csv 让主管人工 |
| 私钥泄漏 | 存档密文可被解密 | 严格 chmod 600 + docker :ro 挂载 + 定期轮换 |
| Docker Desktop 未启动 | 全套挂 | workbuddy 每 10 分钟检查 |
| xlsx 主管忘导 | roster 停在旧数据 | workbuddy 监听 mtime,2 天没变提醒 |
